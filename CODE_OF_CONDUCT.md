# Code of conduct

## Our standard

We want this project to be useful and safe for WooCommerce merchants, developers, and contributors. Be respectful, constructive, patient, and specific. Assume good intent while discussing the work, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sexualized language, deliberate intimidation, publishing another person's private information, spam, and sustained disruption.

## Privacy

Never post customer, order, payment, credential, license, production database, or other private data. Use synthetic examples and redact screenshots and logs before sharing them.

## Enforcement

Project maintainers may edit or remove content, close or lock conversations, reject contributions, or restrict participation when needed to protect contributors and users.

Do not post conduct reports containing personal or private data in a public issue. Use GitHub's built-in content reporting tools for abuse hosted on GitHub. Maintainers may also act on violations they observe in project spaces.

This code applies in repository discussions, issues, pull requests, reviews, and other project spaces.
