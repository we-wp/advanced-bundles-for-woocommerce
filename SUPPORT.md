# Support

## Free plugin

Use [GitHub Issues](https://github.com/we-wp/advanced-bundles-for-woocommerce/issues) for reproducible bugs in the latest Free release.

Include:

- Advanced Bundles version.
- WordPress, WooCommerce, and PHP versions.
- HPOS status and whether you use classic or block cart and checkout.
- Clear reproduction steps with test products.
- Expected and actual behavior.

Remove store, order, customer, credential, and payment data before posting.

Before opening a bug report:

1. Confirm the problem still happens with the [latest release](https://github.com/we-wp/advanced-bundles-for-woocommerce/releases/latest).
2. Review the [setup guide](https://we-wp.com/guides/how-to-create-woocommerce-product-bundles) and [known limitations](https://we-wp.com/docs/known-limitations).
3. Use the [interactive demo](https://demo.we-wp.com/plugins/advanced-bundles/) to compare the same workflow in an isolated synthetic store.
4. Search [existing issues](https://github.com/we-wp/advanced-bundles-for-woocommerce/issues) for the same problem.

## Usage and compatibility

Read the [documentation](https://we-wp.com/docs) and [known limitations](https://we-wp.com/docs/known-limitations) first. Community support has no guaranteed response time.

For product ideas, use the [feature request template](https://github.com/we-wp/advanced-bundles-for-woocommerce/issues/new?template=feature_request.yml). Explain the store workflow and desired outcome. A request does not promise inclusion or a release date.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).
